  # TabScore Enhancer

**Version 1.0 — Windows**

## Overview

TabScore Enhancer is a Windows application that improves the readability of PDF tablature scores created from Guitar Pro Songbooks.

It has been tested on Windows 11 computers and consistently improves the readability of four-string bass tablature.

The application is primarily intended for four-string bass scores. It may also work with other types of tablature, but these have not been extensively tested.

## What It Does

TabScore Enhancer modifies the visual presentation of a PDF score:

* Grays the standard music notation to make it less visually prominent.
* Increases the size and boldness of tablature numbers to make them easier to follow.

**Important:** Enlarged tablature numbers may overlap adjacent strings. When the score contains chords, some information may be obscured as a result.

## How to Use

1. Double-click `TabScoreEnhancer.exe` to open the application. After launching, the application may take a few moments to display the input dialog. Please be patient.
2. Use the Browse button to select the PDF score created from Guitar Pro Songbooks.
3. Choose a name and location for the enhanced PDF, or accept the suggested filename and location.
4. Click **Create Enhanced PDF** to begin processing.
5. The enhanced PDF will be saved to the selected location.

## Important Information

* The original PDF file is never modified.
* A new enhanced PDF is created.
* The application has only been tested with PDF files created by printing from Guitar Pro Songbooks.
* Other PDF sources and tablature formats have not been extensively tested.

## System Requirements

* Windows 11 (64-bit)
* No separate Python installation is required.
